# Elevate Health Chiropractic — Redesign

A private, static redesign concept for Elevate Health Chiropractic in South Burlington, Vermont.

## Project structure

- `dist/` — deployable static site
- `.openai/hosting.json` — Site hosting configuration

## Local preview

From this directory, run:

```powershell
python -m http.server 4173 -d dist
```

Then open `http://localhost:4173`.
